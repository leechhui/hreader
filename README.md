# 简读 · TXT 小说阅读器

一个纯前端、单文件（零依赖）的 TXT 小说阅读工具，双击 `index.html` 即可在浏览器中使用，支持 PC 与手机。

## 快速开始

1. 用浏览器（Chrome / Edge / Firefox / Safari 等现代浏览器）打开 `index.html`
2. 在「书库」页点击或拖入 `.txt` 文件；或粘贴 txt 链接导入
3. 开始阅读 —— 进度会自动保存在本机，下次打开继续

> 也可以直接扔到任意静态服务器上访问，效果相同。

## 功能

| 功能 | 说明 |
| --- | --- |
| 导入 | 本地 .txt 文件（拖拽 / 点击），或通过链接导入（直连，可切换跨域代理）；支持 AES-GCM 加密的 .txti 文件（输入密码解密） |
| 编码识别 | 自动识别 UTF-8 / GB18030(GBK) / UTF-16（含 BOM 检测） |
| 自动分章 | 默认规则 `^\s*第\s*[一二三四五六七八九十百千0-9]+\s*[章节卷集]`（容忍行首/数字前后空白，含全角空格），可在设置中自定义正则 |
| 分页阅读 | 按视口高度自动分页，每页恰好一屏、页内无需滚动；触屏上下滑动翻页（上滑下一页） |
| 笔记 | 选中文本右键（或长按）添加 / 修改笔记，选中文本自动作为引用，可随时跳回 |
| 笔记导出 | 一键导出全书笔记：Markdown / 纯文本 / JSON 三种格式 |
| 全文搜索 | 跨章节检索，点击结果直接跳转并高亮；结果分页自动定位到当前阅读位置并高亮「当前位置」 |
| 选中菜单 | 选中文本后自动弹出「复制 / 笔记 / 搜索 / 标记」横排菜单，右键菜单与之一致；点「标记」选择类型；跨行选区仅「复制」可用 |
| 实体标记 | 右键（或长按）选中文本 → 标记为男性人物 / 女性人物 / 地点 / 组织 / 其他，男女双色；样式可选波浪线 / 横线 / 文字色 / 背景色 |
| 标记管理 | 「笔记」面板切到「标记」页：修改标记词 / 类型、删除、导出（Markdown / 纯文本 / JSON） |
| 进度记录 | 自动记住章节与页码，书库中显示每本书阅读百分比 |
| 夹页 | 右下角 📌 常驻按钮（悬浮球上方）：夹住当前页（最多 5 个），翻到别处后一键跳回并保留；可反复来回、单个/全部松开；仅当前会话，关书/刷新即清空 |
| 密码防护 | 设置密码后每次进入需解锁（轻量本地锁，非加密，可修改/关闭） |
| 文件处理 | 书库内「文件处理」：批量清理 / 加密 .txti / 解密（仅桌面 Chrome/Edge，移动端隐藏） |
| 书库 | 多本书管理，支持按书名 / 导入时间 / 最近阅读时间排序；删除书籍时笔记与进度一并清理 |
| 备份导出/导入 | 书库内「导出备份 / 导入备份」：可勾选多本，打包为 `.hbak`（gzip 压缩 + AES-GCM 加密，含全文、标记、笔记与阅读进度）；导入时新书直接入库、已有书按引用/标记词去重合并 |
| 阅读设置 | 主题、字号、行距、正文字体、字间距、段间距（顶栏「Aa」可快速调整） |

## 快捷键

- `←` / `→` / `↑` / `↓`（或 `PgUp` / `PgDn`）：翻页
- 书架（书库页）：`←` / `→` / `↑` / `↓`（或 `PgUp` / `PgDn`）翻书架页
- `Home` / `End`：跳到第一章 / 最后一章
- `Esc`：关闭面板
- `j`：夹住 / 松开当前页（最多 5 页）
- 笔记 / 标记弹窗：`Esc` 取消，`Ctrl+Enter`（或 `Cmd+Enter`）保存
- 点击标记词（波浪线）：弹出「复制 / 搜索」菜单
- 选中文本：自动弹出「复制 / 笔记 / 搜索 / 标记」横排菜单；右键菜单与之一致，点「标记」选择类型
- 跨行选区（多段落）：仅「复制」可用，其余菜单项禁用
- 触屏：上下滑动翻页（上滑下一页）；长按拖选弹出菜单

## 数据与隐私

- 书籍原文存入浏览器 **IndexedDB**，设置与进度存入 **localStorage**
- 所有数据仅保存在本机，**不上传任何内容**；清理浏览器数据会一并删除
- 「导出备份」生成的 `.hbak` 文件为本地加密文件（AES-256-GCM，密钥=SHA-256(密码)，先 gzip 压缩再加密），需密码才能导入还原

## 链接导入与跨域

受浏览器同源策略（CORS）限制，直连部分网站会失败。此时：

- 在导入框右侧选择代理（allorigins / corsproxy.io）
- 或在「设置」中填写自定义代理模板，用 `{url}` 占位链接

**网盘链接（百度网盘 / 阿里云盘 / 115 等）**：分享链接需要登录与提取码，浏览器无法直接解析（即使走代理拿到的也只是网页而非 txt 正文）。请先下载 `.txt` 到本地再导入，或粘贴该文件的直链（direct link）。

## 部署到服务器

- **静态部署**：把 `index.html` 放到任意静态服务器（Nginx / GitHub Pages / 对象存储等）即可，功能与本地打开一致。
- **与本地打开（file://）的区别**：部署后同源或支持 CORS 的 txt 直链可直接导入，浏览器权限（剪贴板等）更稳定。
- **可选后端代理（解决 CORS）**：`node server.js`（零依赖，Node 18+）启动后同时提供静态服务与 `/proxy` 抓取端点；页面链接导入时代理选「服务器 /proxy」，服务端抓取 txt 直链，彻底绕开浏览器跨域。
- **注意**：`/proxy` 只解决跨域；百度网盘等需要登录/提取码的分享链接依旧无法解析（平台鉴权限制）。对外公开部署时，`/proxy` 可被他人用于抓取公网 URL（已内置内网地址拦截，如需更严可自行加鉴权）。

## 安装为 App（全屏体验）

PWA 支持：部署到服务器后，可「添加到主屏幕 / 安装应用」，启动为**独立窗口**（隐藏地址栏，接近原生 App）。

- **iOS Safari**：打开页面 → 分享按钮 → **添加到主屏幕** → 从主屏幕图标启动（全屏、无地址栏）
- **Android Chrome**：打开页面 → 菜单 → **安装应用 / 添加到主屏幕**
- 需要 **http/https** 环境（`node server.js` 或任意静态服务器），`file://` 直接打开无法安装为 App
- 窗口样式由 `manifest.webmanifest` 的 `display` 控制：默认 `standalone`（保留状态栏）；若想连状态栏也隐藏，改为 `fullscreen`
- **离线可用**：内置 Service Worker（`sw.js`）缓存应用外壳，首次联网打开后即可离线启动/使用（书籍等数据本就在本地 IndexedDB）

## 配套命令行工具（txti.js，Node 18+，零依赖）

```bash
# 批量清理文本：去行首尾空白（含全角空格）、去空行
node txti.js clean 神汝录.txt                       # 原地清理
node txti.js clean ./books --dry-run                 # 预览目录下所有 .txt，不改动
node txti.js clean ./books --out ./cleaned           # 清理后输出到目录，保留原文件

# 加密为 .txti（AES-256-GCM，密钥=SHA-256(密码)，nonce=前12字节）
node txti.js encrypt 神汝录.txt -p 123456            # → 神汝录.txti
node txti.js encrypt 神汝录.txt --password-env PW -n 神汝录

# 解密回明文（校验用）
node txti.js decrypt 神汝录.txti -p 123456 -o 还原.txt
```

- 加密格式与阅读器一致，解密后明文：第一行 `TXTIV1`、第二行小说名、其余正文
- `clean` 统一输出 UTF-8（自动识别 BOM / UTF-8 / GB18030 / UTF-16 输入）
- 也可作为库使用：`const { encryptTxt, decryptTxti, cleanText } = require('./txti.js')`
